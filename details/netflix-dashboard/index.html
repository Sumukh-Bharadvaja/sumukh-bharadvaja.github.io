Overview

An interactive Tableau dashboard exploring Netflix titles by genre, country, rating, and trends over time. Includes distribution of Movies vs TV Shows, world map of production countries, ratings breakdown, and yearly trends.

  • Remove repeated titles (de‑duplicate) using transforms.

  • Derive release year, primary country/genre before import.

Detailed Explanation

Dataset & Fields

The cleaned Netflix dataset includes title, type (Movie/TV Show), listed_in (genres), country (possibly multi‑valued), rating (TV‑MA, TV‑14, etc.), and date_added/release_year. Before modeling, multi‑valued fields are normalized to a primary value to enable unambiguous aggregations.

Data Preparation Workflow

  • De‑duplication: Remove repeated titles by canonical title + type; keep the most recent date_added when duplicates exist.
  • Normalization: Split comma‑separated country and listed_in; select primary country/genre for top‑level metrics; retain full lists for drill‑downs.
  • Cleaning: Trim whitespace, unify casing (Title Case for titles, upper for codes), and standardize missing values to NULL.
  • Derivations: Extract release_year, compute content_mix (Movie vs TV %), and create rating_bucket (e.g., TV‑MA, TV‑14, PG).

Modeling & Interactions in Tableau

  • Parameters: YearParam (single year focus) and GenreParam (filter treemap/ratings).
  • Calculated fields:
    • Movies vs TV Share for the donut chart and KPI tiles.
    • YoY Change for trend deltas in tooltips and labels.
    • Rating Bucket to consolidate similar rating strings.
  • Dashboard actions: Select in one view highlights and filters related views; tooltips show exact counts/percentages.

Design Choices

  • Layout: KPI + composition on the left, exploration center, geography right, trends at bottom for narrative flow.
  • Color: Netflix‑inspired red palette with accessible contrast; consistent category hues across views.
  • Responsiveness: Fixed 16:9 embed for crisp rendering on 1920×1080 displays.

Limitations & Next Steps

  • Primary country/genre simplifies multi‑country/genre titles; a multi‑select drill‑down can complement this view.
  • Extending with time to completion (from date_added) and availability windows would enrich temporal analysis.
