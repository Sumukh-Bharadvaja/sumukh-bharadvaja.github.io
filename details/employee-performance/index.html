Employee Performance Analysis

Data Analytics | EDA, classification, and drivers of performance

PythonPandasSeabornScikit‑learn

Overview

Analyzed the INX Future Inc. employee dataset (≈1200 rows × 28 columns) to identify factors that influence the ordinal PerformanceRating and to build a model that predicts ratings for hiring/support decisions.

Data

  • Features: mix of numerical, ordinal, and categorical (e.g., EmpEducationLevel, EmpWorkLifeBalance, EmpDepartment, JobRole).
  • Preprocessing: manual/frequency encoding for categoricals; standardization for numeric where relevant.
  • EDA: univariate, bivariate, and multivariate analysis per department; correlation profiling.

Methods

  • Models: Support Vector Classifier, Random Forest, Artificial Neural Network (MLP).
  • Validation: held‑out split with accuracy as the primary metric for the ordinal classification target.
  • Feature importance and partial insights via tree‑based models and correlation analysis.

Performance

Model Accuracy Notes
ANN (MLP)≈95.8%Best performing model reported in notebooks/summary
Random Forest—Used for feature importance and baselines
SVC—Baseline classifier

Key Insights

  • Positive correlation with rating: EmpEnvironmentSatisfaction, EmpLastSalaryHikePercent, EmpWorkLifeBalance.
  • Distinct rating distributions across departments and job roles.
  • Encoding categorical predictors was critical for downstream modeling.
