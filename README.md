# Simple Portfolio

A clean, no-dependency portfolio (HTML + CSS + tiny JS).

## Structure
- `index.html` — main page
- `assets/css/styles.css` — styles
- `assets/js/main.js` — small behaviors (nav, smooth scroll, skills)
- `assets/img/` — put images here

## Customization
- Replace "Your Name" and text with your details.
- Update skills in `#skills` list — set `data-level` for each bar (0–100). Percentages are not displayed.
- Add/edit project cards under `#projects`.
- Update contact links in `#contact`.

## Run
Just open `index.html` in a browser.
